# HBD Laeli — Interactive Edition 💗

Website surprise ulang tahun interaktif untuk Laeli Nurhidayah dari Zidan Reksa Pratama.

## Fitur
- Opening screen + tombol "Buka Kejutan"
- Animasi hati dan confetti
- Backsound instrumental lembut yang looping dan dibuat langsung di browser (tanpa file musik eksternal)
- Tombol Music untuk mute/unmute backsound
- Scroll reveal animation
- Amplop interaktif yang membuka surat
- Foto pasangan + lightbox
- Kartu "3 hal kecil" yang bisa ditekan
- Tombol Make a Wish
- Final surprise + confetti besar
- Responsive untuk HP
- Tetap berjalan sebagai static website, tanpa backend

## Menjalankan
Buka `index.html` di browser.

## Upload online
### GitHub Pages
1. Buat repository baru.
2. Upload semua file/folder.
3. Settings → Pages.
4. Deploy dari branch `main` dan folder `/root`.

### Netlify
Drag & drop folder project ke Netlify Drop.

### Vercel
Import repository GitHub sebagai project static.

Foto sudah berada di `assets/laeli.jpeg` dan `assets/kita.jpeg`.
